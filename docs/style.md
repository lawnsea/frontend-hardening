# Prose style

Applies to all prose in this repo: comments, docs, error messages, commit messages, issues, and PRs.

## Be succinct

Use no more words than the idea needs. Prefer short declarative sentences, one idea each.

## Summarize and link

Give the reader only what they need here, and link to an authoritative source for the rest.

> [Web components](https://developer.mozilla.org/en-US/docs/Web/API/Web_components) are a feature of the web platform allowing a page to incorporate reusable, encapsulated custom elements.

Prefer specs and MDN for web platform features, and a project's own docs for tools.

## Define terms on first use

Bold the term and gloss it in one line:

> **Web Worker:** an isolated, separately scheduled JavaScript environment.

## Lead with the claim

State the point first, then qualify it.

## Be concrete and quantitative

Use a specific example over an abstract description, and numbers over adjectives. State limitations plainly.

## Error messages

Say what failed and what the reader can do. Link to details rather than embedding them.
